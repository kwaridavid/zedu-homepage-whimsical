# Zedu public homepage copy

This standalone static page is a local copy of the public pre-sign-in landing page at [zedu.chat](https://zedu.chat). It follows the page's public sections, copy, and illustrations. The Flutter app repository contains the signed-in client and login screen; the public marketing site is separate, so this folder is based on the live public homepage.

## Run locally

From this folder, run `py -m http.server 4176`, then open <http://localhost:4176>.

The page is static HTML, CSS, JavaScript, and local assets. Set this folder as the Vercel project root with no build command or output directory. Sign-in and form submissions are demo interactions only.
